# Ключи — интерактивный прототип

Статическая сборка прототипа, подготовленная для GitHub Pages.

## Локальная сборка

```bash
npm run build
```

Готовый сайт появится в каталоге `dist`.

## Локальный просмотр

```bash
npm run preview
```

После запуска откройте `http://localhost:4173`.

## Публикация на GitHub Pages

1. Создайте репозиторий и поместите содержимое этой папки в его корень.
2. В настройках репозитория откройте **Settings → Pages**.
3. В разделе **Build and deployment** выберите **GitHub Actions**.
4. Отправьте изменения в ветку `main`. Сценарий публикации запустится автоматически.
